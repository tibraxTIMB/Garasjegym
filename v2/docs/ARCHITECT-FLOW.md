# GarasjeGym — Architect / Samspel
## Produktkrav
- Éi arbeidsflate og éin øktmodell for ny WOD, redigering og individuell PT-tilpassing. Aldri parallell byggar.
- WOD-kortet, byggaren, klokka, resultatføringa, ACTA og treningsplanen skal spegla same del-ID, format, føremål, dosering, samarbeidsreglar og scoring. Resultat må aldri blandast saman med føreskrivne tal.
- Heilskap alltid lett tilgjengeleg. Horisontal delbar på mobil, vertikal delbar og detaljflate på breitt nettbrett. Bruk skjermbreidda, unngå unødvendige panel, sveip og store tomrom.
- Faste formatfargar frå WOD-kortet; farge er støtte, ikkje einaste signal. Korte og presise statusar. Tre prikkar for sekundære handlingar. Utropsteikn opnar konkrete feil og leier til aktuell del/øving/felt. Aldri berre generisk feilmelding.
- Store trykkflater og talfelt, relevant numerisk tastatur. Detaljar ved behov; hovudfokus blir verande. Ingen dobbeltregistrering eller motstridande val.
- Samspel er eit eige programmeringslag: format + øving + dosering + roller + bytetrigger + resultatmodell. Skal på sikt fungera med individuelle, partnar- og lagøkter og ulike format, ikkje som ei samling spesialformat.
- Første kandidat: AMRAP med to partnarar, parallell kondisjonsoppgåve (roing/sykkel/SkiErg), bytte etter stadfesta AMRAP-runde; felles rundar/reps og meter eller kaloriar. Ikkje legg kondisjonsoppgåva inn som ei ekstra AMRAP-øving. Andre kombinasjonar skal ikkje lovast før motor og resultatmodell støttar dei. Ingen automatisk PM5-synk i denne kandidaten.
- Samspel-resultat er lagresultat. Individuell PR skal krevja individuell, dokumentert prestasjon. Verifiser både PR-avleiing og rapport før produksjon.
- PT-tilpassing må ikkje endra bibliotekoriginal, tidlegare loggar eller andre kundar. Verifiser tilgang, atomisk lagring, offline og avbrot. Ingen migrasjon/nullstilling av eksisterande data utan eksplisitt mandat.
- Før publisering: full byggkontroll, mobile skjermtestar (portrett/landskap), reell overgang byggar → lagring → kort → timer → resultat → historikk/plan, feil- og angrescenario, bevaring av eldre WOD-ar. Test berre med isolerte data. Ingen publisering før eksplisitt godkjenning og grøne kontrollar.
